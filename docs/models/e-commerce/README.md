# E-commerce Model

An educational e-commerce application for exploring domain modeling and architecture patterns through a catalog-to-order flow. It is independent from the event-driven data platform and clinical-orders learning models.

## Specifications

- [Functional specification](specs/functional.md) — learning goals, users, capabilities, scope, and acceptance criteria.
- [Technical specification](specs/technical.md) — modular architecture, domain modules, technology constraints, quality goals, and open decisions.

## Status

Design direction is documented. Framework, persistence, web interface, and event adapter remain open technical decisions in the technical specification.

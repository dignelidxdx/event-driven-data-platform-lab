# Clinical Orders Model

A separate, design-only educational scenario for exploring order coordination across fictional prescription, validation, laboratory-capacity, and notification contexts. It does not authorize implementation or real clinical use and is not connected to the e-commerce or data-platform models.

## Specifications

- [Functional specification](specs/functional.md) — intended users, illustrative use cases, boundaries, and questions requiring domain clarification.
- [Technical specification](specs/technical.md) — candidate contexts, event flow, consistency and saga considerations, and safeguards.

## Status and safety boundary

This is a conceptual exercise only. It uses no patient data, clinical integrations, or medical decision logic. Several workflow and business rules remain intentionally unresolved.

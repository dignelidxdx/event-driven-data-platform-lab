# Stakeholder Walkthrough

Present the proposal in the order stakeholders need to understand it: problem and scope, requirements, proposed design, important alternatives and trade-offs, validation evidence, risks, and decisions or questions requiring alignment.

Use a small number of readable C4 or workflow diagrams. Explain technical consequences in terms of user outcomes, delivery cost, operational responsibility, and how the solution can evolve. Distinguish agreed requirements, design decisions, assumptions, and open questions.

Capture feedback and decisions. Update RFCs, ADRs, and the [System Design Document](../artifacts-and-templates/system-design-document.md), then link the agreed technical sequence to the [Delivery Framework](../delivery-framework/README.md).

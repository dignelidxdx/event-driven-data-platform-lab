# Deep Dives

Select the few design areas where deeper analysis could alter the solution or materially reduce risk. Common areas include storage and indexing, transaction boundaries, consistency, event delivery, scaling, caching, security, failure handling, and operations.

For each topic, state the question, evidence, alternatives, assumptions, and conclusion. Use focused diagrams and experiments rather than broad inventories. For database performance, inspect representative queries with `EXPLAIN` or the database's equivalent and record relevant data shape and plan findings using the [database query plan review](../artifacts-and-templates/database-query-plan-review.md).

The [Delivery Framework deep dives](../delivery-framework/06-deep-dives.md) describes the technical analysis areas and related artifacts.

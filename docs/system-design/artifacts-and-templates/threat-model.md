# Threat Model Template

## Scope and system sketch

Link the relevant C4 and data-flow diagrams. Mark trust boundaries and entry points.

## Assets and security goals

List sensitive data, credentials, operations, and required protections.

## Actors and threats

For each plausible threat, record the affected asset or boundary, impact, likelihood rationale, and current controls.

| Threat scenario | Asset/boundary | Impact | Existing controls | Mitigation or owner |
|---|---|---|---|---|

## Abuse and failure cases

Consider unauthorized access, privilege misuse, injection, replay, resource exhaustion, data exposure, and dependency compromise as relevant to the system.

## Validation and residual risk

Record checks, experiments, unresolved risks, owners, and review triggers. Avoid treating this template as a substitute for security review where required.

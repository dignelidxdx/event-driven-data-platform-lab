# Request for Comments Template

## Summary

State the proposed change and the feedback or decision requested.

## Problem and goals

Describe user impact, scope, goals, and non-goals.

## Proposal

Explain behavior, interfaces, data flow, architecture, and migration where relevant.

## Alternatives

Compare plausible options and their trade-offs.

## Risks and open questions

List unresolved concerns, owners, and how feedback can resolve them.

## Rollout and validation

Describe experiments, acceptance criteria, rollout, and rollback considerations.

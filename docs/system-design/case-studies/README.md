# Case Studies

Apply the [System Design Process](../system-design-process/README.md) and [Delivery Framework](../delivery-framework/README.md) to different workloads. These are learning exercises, not claims about the internal architecture of named companies. Each study should state assumptions, compare alternatives, and show how scale and quality goals affect the design.

- [URL shortener](url-shortener.md)
- [Social feed](social-feed.md)
- [Messaging platform](messaging-platform.md)

Start with the scenario and workload, then work through requirements, entities, contracts, data flow, architecture, deep dives, and stakeholder review. Link supporting diagrams and decisions as the studies are expanded.

# TypeScript Onboarding

1. Review JavaScript values, functions, modules, asynchronous behavior, and error handling.
2. Learn TypeScript types, narrowing, generics, module settings, and compiler diagnostics.
3. Practice validating untrusted input at runtime; static types do not validate network or persisted data.
4. Learn the repository's package manager, scripts, formatting, linting, test, and build commands.
5. Implement a small vertical slice with a domain rule, application use case, port, and adapter.
6. Add focused tests and review module import boundaries.

Use strict compiler settings and keep domain code independent of web frameworks, databases, and transports, consistent with this lab's architecture rules.

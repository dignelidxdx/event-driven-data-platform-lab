# Language Onboarding Guides

These guides are learning paths for a language after the project has selected it. They complement the [language comparison](../../technology/language-comparison.md); they do not replace the requirements-based selection decision.

- [TypeScript](typescript.md)
- [Go](go.md)
- [Java](java.md)
- [Ruby](ruby.md)

Each path should progress from language fundamentals to project tooling, testing, a small vertical slice, and the conventions used in this repository. Verify version-specific commands against the chosen toolchain when the project adopts a language.

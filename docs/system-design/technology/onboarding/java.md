# Java Onboarding

1. Learn classes, records, interfaces, generics, collections, exceptions, and package visibility.
2. Understand object lifecycle, immutability, resource management, and the Java memory model at a practical level.
3. Learn the selected JDK, build tool, dependency management, formatting, static analysis, and test workflow.
4. Practice unit tests and a small HTTP or command-line vertical slice using the framework selected by the project.
5. Separate domain types and rules from framework annotations and persistence models where the boundary benefits maintainability.
6. Learn logging, configuration, health checks, and packaging for the target runtime.

Record JDK and framework versions in project configuration when Java is adopted; this guide intentionally avoids prescribing versions.

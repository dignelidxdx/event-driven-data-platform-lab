# Ruby Onboarding

1. Learn objects, blocks, modules, exceptions, collections, and Ruby's dynamic dispatch.
2. Practice dependency management and the project's chosen Ruby version manager and package workflow.
3. Learn the selected test framework, formatting and linting tools, and how the application is started locally.
4. Build a small domain object and use case without coupling domain rules to web or persistence libraries.
5. Add a thin endpoint or command adapter and tests for validation, expected behavior, and failure cases.
6. Learn the framework's conventions, configuration, logging, database migrations, and deployment model.

Treat metaprogramming as a tool for specific needs; clear explicit behavior is usually easier for a learner to trace.
